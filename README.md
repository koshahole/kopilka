# Копилка 300 000 ₽

Совместная копилка-календарь с Telegram Mini App, учётом бюджета, уведомлениями и напоминаниями.

## Возможности

- 🏦 Копилка: учёт купюр 100/200/500/1000 ₽, прогресс до 300 000 ₽
- 💳 Бюджет: доходы и расходы, категории, статистика и **просмотр операций за любой прошлый месяц**
- 📅 Календарь: операции, копилка и **напоминания**
- 🔔 Уведомления в Telegram: приход/расход, изменения копилки и напоминания — приходят **обоим участникам**

## Переменные окружения (Vercel)

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) |
| `WEBAPP_URL` | `https://ваш-проект.vercel.app` |

## Хранилище

Подключите Vercel KV: **Storage → Create Database → KV**, затем привяжите к проекту.

## Уведомления в Telegram

Уведомления работают так: приложение отправляет данные пользователя на `/api/register`,
а сервер рассылает сообщения всем подписчикам.

### Что нужно сделать один раз

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Добавьте `TELEGRAM_BOT_TOKEN` и `WEBAPP_URL` в переменные окружения Vercel и перезадеплойте.
3. Установите webhook (откройте ссылку в браузере, подставив токен):

   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ваш-проект.vercel.app/api/telegram-webhook
   ```

4. **Оба участника должны открыть приложение из бота** (кнопка в чате) — тогда они
   автоматически зарегистрируются и получат уведомления.

### Если уведомления не приходят

Откройте приложение → кнопка **🔔** в шапке → проверьте статус и нажмите
**«Отправить тест»**. Возможные причины:

- **«Бот настроен: нет»** — не задан `TELEGRAM_BOT_TOKEN` (или нужен перезадеплой).
- **«Зарегистрировано: 0»** — никто не открыл приложение из бота. Telegram не позволяет
  писать первым: пользователь должен сам запустить бота (кнопка/`/start`).
- Webhook не установлен — выполните шаг 3.
- Команды бота: `/start` — подписаться, `/stop` — отключить уведомления, `/status` — прогресс.

## Напоминания

Напоминания создаются в календаре (кнопка **⏰** на дне или «Добавить» в разделе
напоминаний). Можно выбрать, за сколько до события прислать уведомление
(в момент, за 10 мин, 30 мин, час, 3 часа, день).

### Как отправляются напоминания

Время события считается в часовом поясе пользователя и хранится как абсолютная метка,
поэтому напоминания приходят в нужный момент независимо от часового пояса сервера.

Проверка «наступило ли время» выполняется:

1. **Пока приложение открыто** — каждую минуту (работает без настройки).
2. **По расписанию** — эндпоинт `/api/reminders-cron`.

> ⚠️ Vercel Cron на бесплатном (Hobby) тарифе запускается **не чаще раза в сутки**,
> поэтому для точной отправки подключите планировщик ниже.

### Вариант А — GitHub Actions (рекомендуется, без регистраций) ✅

Ничего регистрировать не нужно — достаточно этого репозитория.
Файл `.github/workflows/reminders.yml` уже создан.

1. Убедитесь, что репозиторий на GitHub (он уже есть).
2. Задайте адрес приложения: **Settings → Secrets and variables → Actions →
   вкладка Variables → New repository variable**

   | Name | Value |
   | --- | --- |
   | `WEBAPP_URL` | `https://ваш-проект.vercel.app` |

   *(либо просто впишите адрес прямо в файл `reminders.yml` вместо `your-project`)*
3. Готово. Проверить можно вручную: **Actions → Reminders → Run workflow**.

> Для **публичных** репозиториев Actions бесплатны без ограничений, поэтому
> оставлен интервал 5 минут.
> Для **приватных** бесплатный лимит — 2000 минут/месяц (одна проверка = 1 минута),
> поэтому замените `'*/5 * * * *'` на `'*/30 * * * *'`.
>
> GitHub может задерживать запуск по расписанию на несколько минут при высокой
> нагрузке, а в публичных репозиториях отключает расписание после 60 дней
> без активности — любой коммит включает его снова.

### Вариант Б — cron-job.org (точность до минуты)

Точнее, но требует регистрации на стороннем сайте:

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org).
2. Создайте задачу: URL `https://ваш-проект.vercel.app/api/reminders-cron`, интервал — 1 минута.

В `vercel.json` дополнительно добавлен ежедневный Vercel Cron как резервный вариант.

## API

| Эндпоинт | Методы | Назначение |
| --- | --- | --- |
| `/api/entries` | GET, POST, DELETE | записи копилки |
| `/api/summary` | GET | итоги копилки |
| `/api/stats` | GET | статистика копилки |
| `/api/transactions` | GET, POST, DELETE | операции бюджета |
| `/api/categories` | GET, POST, DELETE | категории |
| `/api/budget`, `/api/budget-stats` | GET | статистика бюджета |
| `/api/reminders` | GET, POST, DELETE | напоминания |
| `/api/reminders-cron` | GET | отправка наступивших напоминаний |
| `/api/register` | POST | регистрация пользователя для уведомлений |
| `/api/notify` | GET, POST | статус и тест уведомлений |
| `/api/telegram-webhook` | POST | webhook бота |
